# Superknown Website (v1.0)

A premium, modern, animation-rich single-page agency website built for **Superknown** and empowered by **Paul Business Solutions (PBS)**.

---

## Brand Foundation & Tech Stack

- **Tech Stack**: HTML5, Vanilla CSS3, ES6 JavaScript, GSAP + ScrollTrigger, Swiper.js, GLightbox, Font Awesome.
- **Branding**:
  - **Primary Color**: Deep Teal (`#145B67`)
  - **Accent Color**: Vibrant Green (`#8DFF00`)
  - **Secondary Colors**: Dark Charcoal (`#121212`), White (`#FFFFFF`), Light Grey (`#F5F7FA`)
  - **Typography**: Montserrat (Google Fonts)

---

## Website Structure (12 Core Sections)

1. **Header / Navigation**: Sticky translucent backdrop, navigation drawer for mobile.
2. **Hero Carousel**: 3 fullscreen slides (6-second autoplay, smooth fade & text reveal).
3. **About Us**: Ronnie Datta's 12+ years story, Mission, and Vision cards.
4. **Services**: Interactive left vertical tab navigation & content swap (Creative & Marketing vs Technology/PBS).
5. **Featured Works**: Masonry portfolio grid with category filters and GLightbox preview modals.
6. **Why Choose Us**: Value proposition pillars + 4 animated stats counters.
7. **Our Process**: 6-step interactive vertical timeline (Discover → Research → Design → Create → Launch → Grow).
8. **Team**: Leadership profiles (Ronnie Datta, Design Specialists, Performance Marketers, PBS Technology Partner).
9. **Clients**: Auto-scrolling infinite logo marquee.
10. **Testimonials**: 5-star review card slider powered by Swiper.js.
11. **Technology Partner**: Spotlight section highlighting Superknown × PBS digital transformation.
12. **Contact & Footer**: Direct action button grid (WhatsApp, Instagram, Email, LinkedIn, Behance, Facebook, Maps), floating WhatsApp launcher.

## Deployment & Hosting

This codebase is static, zero-dependency, and ready for immediate deployment on **GitHub Pages**, Vercel, or Netlify.
To deploy to GitHub Pages:
1. Push this repository to GitHub.
2. Go to **Settings > Pages**.
3. Select `main` branch as the source root (`/`).
4. Save to go live!
