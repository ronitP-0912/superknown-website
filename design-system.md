# Superknown Design System v1.0

## Brand Foundation

**Brand Personality:** Bold, Creative, Modern, Confident, Collaborative.

**Primary Font:** Montserrat - H1: 64px / 700 - H2: 48px / 700 - H3:
36px / 600 - H4: 28px / 600 - Body: 18px / 400 - Small: 14px / 400

## Color Palette

  Usage        Hex
  ------------ ---------
  Primary      #145B67
  Accent       #8DFF00
  White        #FFFFFF
  Dark         #121212
  Light Grey   #F5F5F5
  Text Grey    #666666

## Spacing

8px grid system. Section padding: 120px desktop / 80px tablet / 60px
mobile. Container: 1280px max-width.

## Border Radius

Buttons: 12px Cards: 20px Images: 24px Pills: 999px

## Buttons

Primary: Accent green background, dark text. Secondary: Transparent with
2px accent border. Hover: Lift 6px + glow + 0.3s transition.

## Cards

Soft shadow, rounded corners, hover lift (translateY -8px), subtle
scale.

## Navigation

Transparent over hero, solid after scroll. Smooth scroll for all links.

## Hero

Three fullscreen slides with Swiper.js. Background video/image + dark
overlay. Headline reveal using GSAP.

## Services

Vertical tab navigation on desktop. Horizontal scroll tabs on mobile.
Animated image/content swap.

## Portfolio

Masonry grid. Category filters. Lightbox preview. Lazy-loaded images.

## Animations

-   Fade up
-   Fade left/right
-   Blur reveal
-   Text reveal
-   Counter animation
-   Infinite logo marquee
-   Image zoom on hover
-   Magnetic CTA buttons Keep animations under 500ms where possible.

## Icons

Lucide or Font Awesome. Outline style preferred.

## Accessibility

Minimum AA contrast. Visible focus states. Keyboard navigation. Alt text
for all images.

## Performance

Images: WebP. Videos lazy-loaded. Target Lighthouse \>95.
