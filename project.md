# Superknown Website Project (Version 1.0)

## Project Overview

Build a premium, high-performance marketing agency website for
**Superknown** using **Visual Studio Code**, **HTML5**, **CSS3**, and
**Vanilla JavaScript**. The website should be modern, animation-rich,
mobile-first, and optimized for GitHub Pages deployment.

This is **not** a template-based website. It should be custom-built with
reusable components so PBS can use it as a base for future agency
websites.

------------------------------------------------------------------------

# Tech Stack

-   HTML5
-   CSS3
-   JavaScript (ES6)
-   GSAP (animations)
-   ScrollTrigger
-   Swiper.js (hero & testimonials)
-   GLightbox (portfolio)
-   Font Awesome
-   Lenis (optional smooth scrolling)

No React. No backend. No CMS. No database.

# About

## Story

Ronnie Datta began his creative journey over twelve years ago as an
independent freelancer, helping businesses communicate through
thoughtful branding, visual storytelling, and design. As his experience
and client base grew, so did the ambition to build a creative studio
that offered more than isolated services.

Superknown was founded to bring together designers, editors,
strategists, and marketers into one collaborative agency capable of
delivering complete creative solutions. Today, Superknown partners with
brands across hospitality, education, retail, lifestyle, and emerging
businesses, helping them create memorable identities and meaningful
digital experiences.

## Mission

Empower businesses through purposeful creativity and strategic digital
marketing.

## Vision

Become one of India's most respected creative agencies, recognized for
combining design, storytelling, and technology to build brands that
people remember.

# Developer Notes

Prioritize clean architecture, reusable components, semantic HTML,
accessibility, lazy-loaded media, and modular JavaScript. Keep the
design elegant, modern, and focused on showcasing creative work. The
portfolio should be the visual centerpiece of the website.
